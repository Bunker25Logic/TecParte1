# Asimov Academy - Teste Técnico (Parte 1)

Este repositório contém a Parte 1 do desafio técnico, focada na fidelidade visual e conversão de design para código. O projeto foi construído utilizando **React, Vite e Tailwind CSS**.

### Respostas do Desafio:

**1. Quais IAs você usou?**
Utilizei o google antigravity com o modelo gemini 3 flash. Como possuo certificação recente focada no uso de Inteligência Artificial, apliquei técnicas de engenharia de prompt para guiar a ferramenta como um assistente de produtividade no meu fluxo de trabalho, e não apenas como um gerador passivo de código.

**2. Onde elas ajudaram mais?**
A IA foi crucial para acelerar a montagem da base das seções com o Tailwind. Ela também ajudou bastante a destravar lógicas estruturais e no debug de problemas crônicos de responsividade no mobile. Com prompts bem direcionados descrevendo o comportamento esperado, consegui isolar e corrigir quebras de layout de forma muito satisfatória.

**3. O que você ajustou na mão e por quê?**
Todo o refinamento visual final foi feito na mão, pois a IA adianta a estrutura, mas falha em proporções finas. Ajustei manualmente o sistema de grid/flexbox, tipografia e espaçamentos (paddings e margins). Como consegui extrair os assets e ícones originais do Figma, foquei a codificação manual em aplicar e posicionar cada elemento para obedecer fielmente ao design designado.
